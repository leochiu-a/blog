# leochiu.com

Leo Chiu 的個人網站與部落格。

我是資深軟體工程師，在 KKday Growth Team 工作，主導網站 SEO / AEO（AI 搜尋優化）策略落地，平常在團隊裡推動 AI agent 的開發流程與效能優化。

這裡放我寫的文章，大部分在談 AI 怎麼改變工程師的工作方式。我想把「AI 能做到哪裡、人該站在哪裡」講清楚一點，所以會去讀論文看它的邊界，會寫 AI 時代的認知卸載與認知投降，也寫過模型變強之後、三個月前那套防禦性 Harness 該怎麼重新設計。偶爾寫 Web 平台上的新東西，像 Chrome Built-in AI 和 WebMCP。

首頁的照片可以翻面，一面是工作上的我，一面是下班之後的我。文章也分成這兩種，professional 和 personal。下班之後，想的都是些無關緊要的小事。
